# Logo sources

Third-party marks shown small beside target names, to identify the technologies this bench compares. Each file is
used exactly as published, only scaled in the browser. The app's footer carries the ownership and no-affiliation
notice.

| File | What | Source | Retrieved | Terms |
|---|---|---|---|---|
| `dbt-bit-standalone.png` | dbt logo mark (standalone) | dbt Labs brand assets zip, linked from [getdbt.com/brand-guidelines](https://getdbt.com/brand-guidelines) | 2026-10-23 | [dbt Labs Trademark Policy](https://www.getdbt.com/trademark-guidelines) (15 May 2026): logo use to show the technology in a data stack is allowed if the file and colors are unchanged, it's sized like the other logos, it isn't the only logo, and a no-affiliation disclaimer is shown |
| `malloydata-avatar.png` | Malloy logo | The malloydata GitHub organization's avatar, [github.com/malloydata](https://github.com/malloydata) | 2026-10-23 | No published logo policy found |

Raw SQL, the glossary and the models use simple line icons drawn in `static/js/icons.js`, not brand marks. No Claude
or Anthropic logo is used: no published terms for it were found.
