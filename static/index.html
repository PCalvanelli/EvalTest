    Accuracy vs. cost
    
      
    Each point is a cell. The line is the Pareto frontier: a cell is on it if no other cell is both at least as
        accurate and no more expensive. Cells below the line are dominated however you weigh accuracy against cost.
    
      
    
      
    
      
    
        Table view and break-even values
        
    
        
    Intervals are 95% cluster-bootstrap intervals (prompts resampled with all their runs, 2,000 draws).
          Break-even is the value of a correct answer above which the next frontier cell's extra accuracy pays for its extra cost: V* = Δcost / Δaccuracy − loss.
